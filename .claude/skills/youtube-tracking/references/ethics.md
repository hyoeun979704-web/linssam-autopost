# 약관·개인정보 경계

이 파일은 법률 자문이 아니다. 실제 배포 전에 법률 검토를 받는다. 여기 적힌 것은 설계 기본값을 정하기 위한 정리다.

## 1. 유튜브 약관에서 오는 제약

| 조항 성격 | 내용 | 설계 함의 |
|---|---|---|
| 자동화 접근 금지 | 로봇·봇넷·스크래퍼 등 자동화 수단으로 서비스에 접근하는 것을 금지 | 공식 API가 기본 경로. 스크래핑은 옵트인 |
| 개인정보 수집 금지 | 사용자 이름이나 얼굴 같은 개인 식별 가능 정보 수집 금지 | 댓글 작성자명·프로필 이미지를 그대로 저장하지 않는다 |
| **30일 보관 한도** | 저장한 API 데이터는 30일 내 갱신하거나 삭제 | 원문 축적형 설계가 불가능하다 |
| **7일 삭제** | 사용자 삭제 요청 시 7일 내 삭제 | 삭제 요청을 이행할 수 있는 구조여야 한다 |

30일 한도가 이 스킬의 저장 설계를 결정한다. 시계열을 보려면 매일 스냅샷이 필요한데 그 스냅샷이 정책 대상이다. **원문을 버리고 집계 통계만 남기는 것이 출구다.**

## 2. 개인정보 경계

| 행위 | 판단 | 근거 |
|---|---|---|
| 공개 댓글 본문을 읽고 집계 | 가능 | 집계 결과는 개인을 식별하지 않는다 |
| 작성자명·채널 ID를 원문 그대로 저장 | **피한다** | 유튜브 약관 개인정보 조항. 보관 시 통지 의무가 발생 |
| 작성자별 활동을 시간축으로 추적 | **하지 않는다** | 프로파일링에 해당 |
| 특정 개인의 댓글을 모아 분석 | **하지 않는다** | 동일 |
| 익명화·집계된 통계 보관 | 가능 | 익명 정보는 적용 제외 경로가 있다 |

**식별정보를 보관하면 통지 의무가 발생하는데 이행 수단이 없다.** 한국 개인정보보호법과 유럽 일반개인정보보호법 양쪽에서 정보주체에게 알려야 하는데, 유튜브 댓글 작성자에게 연락할 방법이 없다. 이행 불가능한 의무를 지지 않는 유일한 방법이 처음부터 식별정보를 갖지 않는 것이다.

두 법 모두 익명 정보에 적용 제외 경로를 둔다. 그래서 **집계 전용 설계가 선택이 아니라 요건이다.**

## 3. 저장 규칙

수집 스크립트가 지켜야 할 것 넷이다.

1. **모든 레코드에 `fetched_at`.** 없으면 30일 정책을 이행할 수 없다
2. **30일 갱신·삭제 잡.** 스케줄러가 없으면 스크립트는 미완성이다
3. **작성자 식별정보 제거 또는 해시.** 원문 저장이 꼭 필요하면 작성자명·채널 ID·프로필 URL을 해시하고 솔트를 분리 보관한다
4. **집계본과 원문 분리.** 집계본은 개인을 식별하지 않으므로 보관 제약이 다르다. 장기 시계열은 집계본으로 만든다

권장 저장 형태:

```
raw/            30일 잡 대상. 작성자 식별정보 제거됨
집계/           장기 보관. 개인 식별 불가
  채널지표.csv   date, channel_id, subs_rounded, views, videos, fetched_at
  영상지표.csv   date, video_id, views, engaged_views, likes, comments, fetched_at
  댓글집계.csv   video_id, 수집일, 표본수, 정렬기준, 키워드 top N, 분류 분포
```

## 4. 재배포

수집한 데이터를 외부에 공유하려면 확인이 더 필요하다. 클라이언트 리포트에 넣는 것, 공개 대시보드로 만드는 것, 데이터셋으로 배포하는 것은 각각 조건이 다르다.

- 집계 통계와 인사이트는 대체로 문제가 적다
- 댓글 원문을 그대로 옮기는 것은 저작물 이용과 개인정보 양쪽에 걸린다
- 지표 수치를 재배포할 때는 출처와 수집 시점을 명시한다

**Phase 1의 6번 질문이 "외부 공유"면 여기부터 확인한다.**

## 5. 모델 라이선스

분석에 쓰는 모델도 배포 형태에 따라 제약이 다르다.

- 상업 금지 라이선스 모델을 클라이언트 리포트 생산에 쓰면 위반이다
- 라이선스가 명시되지 않은 모델은 내부 분석과 상업 배포를 구분해 판단한다
- LGPL 라이브러리는 정적 링크 여부에 따라 검토가 필요하다

목록은 `tools.md`에 있다.

## 6. 사용자에게 고지할 것

비공식 경로를 켜기 전에 이 셋을 말하고 승인받는다.

1. 이 도구는 유튜브 약관의 자동화 접근 금지 조항에 저촉된다
2. 계정·IP 차단 가능성이 있고, 클라우드 환경에서는 대부분 차단된다
3. 반환 데이터에 개인 식별정보가 포함되므로 저장 시 제거가 필요하다

승인 없이 실행하지 않는다.
