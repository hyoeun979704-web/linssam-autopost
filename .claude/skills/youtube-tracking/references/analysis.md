# 반응 분석 방법론

수집한 숫자가 무엇을 뜻하고 무엇을 뜻하지 않는지 정한다. 이 파일의 목적은 분석을 화려하게 만드는 것이 아니라 **틀린 결론을 막는 것**이다.

## 1. 표본의 성질을 먼저 안다

댓글은 조회수의 약 0.09%다. 무작위 표본 10,016개 영상 연구에서 영상의 72.6%가 댓글 0개였고, 댓글 100개가 넘는 상위 1.04%가 전체 댓글의 54.6%를 차지했다.

여기서 나오는 결론은 셋이다.

1. **댓글은 시청자의 표본이 아니라 댓글 작성자의 표본이다.** 댓글을 남기는 사람은 남기지 않는 사람과 다르다
2. **비확률 표본에 오차범위를 붙이면 안 된다.** 통계 실무에서 명시적으로 금지된다. "±3%p" 같은 표기를 쓰지 않는다
3. **"시청자의 X%"라는 문장을 쓰지 않는다.** "수집한 댓글 N개 중 M개"로 쓴다

### 정렬이 만드는 편향

| 정렬 | 무엇이 뽑히나 | 쓸 수 있는 것 |
|---|---|---|
| 최신순 | 최근 유입된 시청자, 알고리즘 노출 변화의 영향 | 시점별 반응 변화 |
| 인기순(relevance) | 좋아요를 많이 받은 댓글. **랭킹 기준은 비공개** | 대표적 반응 파악 |

API 기본값은 최신순이고 웹 UI 기본은 인기순이다. 같은 영상이라도 표본이 달라진다. **정렬 기준을 결과물에 반드시 적는다.** 인기순으로 뽑은 표본은 어떤 분포 주장에도 쓸 수 없다.

### 봇·스팸

식별 단서는 반복 문구, 동일 시각 집중 게시, 외부 링크, 프로필 신설, 무관한 홍보다. 완전 제거는 불가능하다. 제거한 건수와 기준을 결과물에 적는다.

## 2. 감성 분류의 한계

**정확도 80% 분류기는 참값 5%를 23%로 보고한다.** 4.6배다. 소수 범주일수록 오차가 커진다.

같은 "정확도 80%"라도 진양성률과 위양성률의 조합에 따라 편향 방향이 뒤집힌다. 보정 공식이 존재하지만 위양성률 추정이 5%포인트만 어긋나도 결과가 12.3%가 되거나 0%가 된다.

**모델을 더 좋게 만들어 해결하는 경로는 닫혀 있다.** 감성 분류의 최고 수준 정확도가 66% 수준이고, 사람끼리의 일치도 천장이 67.5%다.

그래서 이렇게 쓴다.

| 쓸 수 있는 것 | 쓸 수 없는 것 |
|---|---|
| 같은 채널 영상 간 상대 비교 | 소수 범주의 절대 비율 |
| 시간축 추세 방향 | "부정 반응이 N%" |
| 극단값 탐지(평소와 다른 영상 찾기) | 절대 임계값 판정 |

### 한국어 댓글 고유 함정

반어법, 밈, 이모지, 신조어, 자모 분리, 초성체가 전부 분류기를 흔든다. "미쳤다"가 극찬일 수도 비난일 수도 있다. 분류 결과를 그대로 쓰지 말고 상위 빈도 댓글을 직접 읽어 대조한다.

## 3. 키워드·토픽 추출

| 방법 | 언제 쓰나 | 한계 | 한국어 |
|---|---|---|---|
| 빈도 | 첫 탐색 | 불용어·조사에 압도된다 | 형태소 분석 선행 필수 |
| TF-IDF | 영상 간 차별 키워드 | 문서 집합이 작으면 불안정 | 동일 |
| KeyBERT | 문맥 반영 키프레이즈 | 임베딩 모델 품질에 좌우 | 한국어 임베딩 백본 필요 |
| BERTopic | 토픽 군집 | 댓글이 짧아 군집이 뭉개진다. 최소 수천 건 필요 | 동일 |
| LDA | 토픽 모델 고전 | 짧은 텍스트에 약하다 | 권장하지 않음 |

**댓글은 짧다.** 토픽 모델링은 댓글 수가 수천 건 이상일 때만 시도한다. 그 이하면 빈도와 KeyBERT로 충분하다.

형태소 분석기는 `kiwipiepy`를 쓴다. 이유는 `tools.md`에 있다.

## 4. 지표 해석

| 지표 | 계산 | 공개 근거 | 주의 |
|---|---|---|---|
| 좋아요율 | 좋아요 / 조회수 | **없음** | 절대 벤치마크 금지. 같은 채널 내 비교만 |
| 댓글율 | 댓글수 / 조회수 | **없음** | 동일 |
| 노출 클릭률 | 클릭 / 노출 | 유튜브가 "절반은 2~10%"라고 밝힌 것이 유일 | **본인 채널만**. 남의 채널은 알 수 없다 |
| 참여 조회수 | API 제공 | — | 정의 변경을 피하는 기본 축 |
| 시청 지속률 | API 제공 | — | 본인 채널만. 1을 넘을 수 있다 |

**시중 벤치마크를 쓰지 않는 이유**는 값이 틀려서가 아니라 **분모가 서로 다르기 때문이다.** 어떤 조사는 구독자로 나누고 어떤 조사는 조회수로 나눈다. 자릿수가 다른 값을 같은 이름으로 부른다. 비교 대상이 아니다.

### 싫어요

2021년 비공개 처리됐다. 유튜브가 근거로 공개한 것은 2021년 7월 분석이라는 각문 한 줄뿐이다.

제3자 복원 서비스는 표본이 공개 좋아요의 1% 미만인 경우가 관측됐고(어떤 영상은 6표), 표시값이 그 서비스 자체 설명과도 맞지 않았다. 실측 반증 사례에서 10~20배 과대 또는 5배 과소였다.

**지표로 쓰지 않는다.** 부정 반응을 보려면 댓글을 읽는다.

## 5. 남의 채널 시청자 추정

직접 볼 수 없다. 추정만 가능하고, 추정임을 결과물 표면에 적는다.

| 추정 대상 | 방법 | 신뢰도 | 최소 표본 |
|---|---|---|---|
| 주 시청 언어 | 댓글 언어 분포 | 중. 댓글 작성자 편향 | 댓글 200건 이상 |
| 관심 주제 | 댓글 키워드, 영상 소재 반응 차이 | 중 | 영상 10개 이상 |
| 연령대 | 어휘·밈·레퍼런스 | **낮음.** 근거 약함 | 정량 주장 금지 |
| 성별 | 추정하지 않는다 | — | — |
| 지역 | 댓글 언어 + 업로드 시간대 반응 | 낮음 | 정성 참고만 |

연령과 성별은 **추정 결과를 수치로 제시하지 않는다.** 정성 서술로만 쓰고 근거를 함께 적는다.

## 6. 결과물에 반드시 붙일 것

1. 수집 규모, 정렬 기준, 수집 시각
2. 전체 대비 표본 비율 (댓글 N개 / 총 댓글 M개)
3. 분류기를 썼으면 모델명과 한계 문장
4. 추정 항목과 각각의 신뢰도
5. 요청받았으나 얻을 수 없던 항목과 그 이유

## 7. 하지 않는 것

- 댓글 비율을 시청자 비율로 환산
- 비확률 표본에 오차범위 부기
- 외부 벤치마크와 좋아요율·댓글율 비교
- 싫어요 복원 서비스 값을 지표로 사용
- 감성 분류 결과의 소수 범주 절대 비율 제시
- 연령·성별 추정치를 수치로 제시
- 댓글 수천 건 미만에서 토픽 모델링 결과를 결론으로 사용
- 정렬 기준을 밝히지 않은 댓글 분석 보고

## 8. 추정을 해야 할 때 — 근거와 한계

얻을 수 없는 것을 추정으로 대신할 때 쓴다. **추정이 나쁜 게 아니라 추정을 실측처럼 말하는 것이 나쁘다.**

### 인구통계 추정

텍스트로 작성자 속성을 추정하는 연구는 존재하고 성능 수치도 있다. 페이스북 장문에서 성별 91.9%, 연령 상관 0.84 수준이다. 다만 **그 수치를 유튜브 댓글에 가져올 수 없다.**

이유가 다섯이다.

1. **검증된 성능은 전부 장문 기준이다.** 페이스북 장문, 메신저 로그, 게시물 이력 전체다. **유튜브 댓글 한 줄 기준 정확도는 어느 연구에도 없다**
2. **줄일 수 없는 오차 바닥이 있다.** 사람과 자동 시스템이 동시에 틀리는 비율이 10~16%다. 데이터를 늘려도 안 줄어든다. 그 사람이 자기 성별과 연결된 언어를 안 쓰기 때문이다
3. **연령은 방향성 편향이 있다.** 나이가 많을수록 더 어리게 추정된다. **집계하면 시청자층이 실제보다 젊게 나온다**
4. **댓글 작성자가 시청자를 대표한다는 실증이 없다.** 온라인 커뮤니티 연구에서 상위 1.3%가 콘텐츠의 74.7%를 생산한다
5. **분류기 출력을 그냥 세면 비율 자체가 편향된다.** 개별 정확도가 85%여도 그렇다. 혼동행렬 기반 보정이 필요하다

한국어 성별 분류는 약 95% 성능의 연구가 있으나 **메신저 구어체 대상**이다. **한국어 연령 추정 연구는 찾지 못했다.**

**개인정보 관점에서 이것은 프로파일링이다.** 유럽 규정의 프로파일링 정의에 정확히 해당하고, 국내법에서는 추정 속성을 **생성하는 행위 자체가 개인정보 처리**다. 방어 가능한 유일한 설계는 가명처리 후 통계 작성 목적으로 순수 집계만 남기는 것이다.

### 시청 지속률 대체

**대체 지표가 사실상 없다.** 공개 신호 중 가장 강한 것이 영상 길이이고, 시청 비율 분산의 58% 이상을 설명한다. 그런데 이건 품질과 무관하다. 길면 완주율이 낮다는 것 이상을 말하지 못한다.

좋아요와 댓글은 약하다. 조회수와 좋아요 비율과 댓글 감성을 **전부 합쳐도 설명력이 0.13~0.19다.** 분산의 80% 이상을 설명하지 못한다.

**"좋아요 비율 X% 이상이면 완주율 Y%" 같은 공식은 존재하지 않는다.** 그런 계수를 제공한 연구가 없다.

가장 많이 재생된 구간 히트맵은 화면에서 읽히지만 **영상마다 정규화되어 절대 수준이 소거된다.** 영상 간 완주율 비교가 원리적으로 불가능하다. 수집 자체도 약관에 저촉된다.

**조회 속도로 지속률을 추정하는 것도 근거가 없다.** 조회수 순위와 시청시간 순위의 상관이 낮고 카테고리에 따라 음수가 되기도 한다.

### 자기 실험으로 대체하기

공식 A/B 테스트는 **제목과 썸네일에만** 적용된다. 최대 3안이고 승자 판정 기준이 클릭률이 아니라 시청 시간 점유율이다. 쇼츠에는 안 된다.

영상 내용이나 편집을 비교하려면 직접 여러 편을 찍어야 하는데 **표본이 문제다.**

| 효과 크기 | 군당 필요 편수 | 총 |
|---|---|---|
| 큼 | 26 | 52편 |
| 중간 | 64 | 128편 |
| 작음 | 393 | 786편 |

**영상 2편 비교는 각 군 표본이 1이다.** 시청자 수를 표본 크기로 쓰면 안 된다. 처치가 영상 단위로 배정되기 때문이다.

순차 비교도 편향된다. **초기 노출은 이미 채널을 아는 시청자에게 더 가고 나중 노출은 새 시청자에게 간다.** 플랫폼이 공식 문서에서 인정한 사실이다.

내 완주율로 남의 완주율을 대신하려면 **두 모집단이 어떻게 다른지 먼저 적어야 한다.** 유입 경로, 구독 여부, 기대치가 다르다. 그 차이를 명시하지 않은 이전은 부당 일반화다.

### 설문

커뮤니티 탭 투표에서 크리에이터가 받는 것은 **노출수와 투표 집계값뿐이다.** 투표 자격, 결과 공개 여부, 인구통계 분해 제공 여부는 공식 문서에서 확인되지 않는다.

비확률 표본의 실제 오차는 크다. 확률 기반 패널이 평균 2.6%포인트일 때 온라인 자기선택 표본은 5.8%포인트이고, **18~29세는 11.2%포인트**다. 팬 투표는 그보다 통제가 더 약하다.

### 표기 규칙

1. **오차범위를 붙이지 않는다.** 비확률 표본에 오차범위를 쓰는 것은 부적절하다고 규정된다
2. **그렇다고 오차가 없는 척도 안 된다.** 다른 용어를 쓰되 가정과 방법을 전부 공개한다
3. **근거 등급을 붙인다.** 높음·중간·낮음·매우 낮음 네 단계로 적고, 경험칙은 명시적으로 매우 낮음이다
4. **숫자를 붙일 수 없으면 확신도만 적는다.** 확신도를 확률로 해석하지 않는다
5. **"응답률" 대신 "참여율"을 쓴다**

### 하지 않는 것

- 댓글로 인구통계를 추정해 "시청자의 X%"라고 말하기
- 좋아요 비율로 완주율을 환산하는 공식 사용
- 가장 많이 재생된 구간으로 영상 간 완주율 비교
- 영상 2~5편 비교하고 포맷 우열 결론
- 추정치에 오차범위 부기
- 서드파티 도구의 추정 시청시간을 검증 없이 인용
