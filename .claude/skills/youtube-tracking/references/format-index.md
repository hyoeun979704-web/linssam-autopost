# 포맷 지수와 채널 샘플링

레퍼런스 채널을 여러 개 놓고 "어떤 포맷이 되는가"를 판단하는 절차다. 채널 크기가 제각각일 때 절대 조회수는 비교 대상이 아니므로 **채널 내부 상대 지수**로 바꾼 뒤 비교한다.

이 절차의 산출물은 `instagram-tracking`, `tiktok-tracking`과 **같은 스키마**를 쓴다. 플랫폼이 달라도 같은 스크립트에 들어간다.

## 1. 표준 산출 파일

### `classified.tsv` — 영상 단위 원장

탭 구분, 헤더 없음, 5열 고정.

```
채널명	영상ID	조회수	포맷코드	제목
```

```
NYANE	Fz3haBoL6fk	267000	OTHER	Try These CUTE Poses 🎀
NYANE	cDmLXECYzHE	7100000	OTHER	The Struggle is REAL!
```

- **채널명**: 표시명을 그대로. 채널 ID가 아니다. 사람이 읽는 축이다
- **영상ID**: 플랫폼 고유 ID. 유튜브는 11자, 인스타그램은 숏코드, 틱톡은 숫자 ID
- **조회수**: 정수. 콤마·단위 접미사 없음. 수집 시점 값
- **포맷코드**: 2절 표
- **제목**: 탭과 개행을 공백으로 치환. 자르지 않는다

헤더가 없는 것은 의도다. 기존 지수 스크립트가 위치 기반으로 읽는다. 열을 추가하려면 **뒤에만** 붙인다.

### 메타 파일

영상마다 `meta/{영상ID}.info.json`과 썸네일을 남긴다. 게시일과 길이가 여기 들어간다. 경과일 보정에 필요하다.

### 채널 단위 파일

배율 계산에 필요한 것만 둔다.

```
채널명	채널ID	구독자	총조회수	수집일
```

## 2. 포맷 코드

기존 분류 체계다. 새 코드를 만들기 전에 이 목록으로 커버되는지 먼저 본다.

| 코드 | 뜻 |
|---|---|
| `B_TRANSFORM` | 비포·애프터 변신 |
| `B_ASMR` | 무대사 ASMR 메이크업 |
| `B_PRODUCT` | 제품 중심 리뷰·시연 |
| `B_TUTORIAL` | 단계 설명형 튜토리얼 |
| `F_OUTFIT` | 착장 룩북·코디 |
| `F_DRESSUP` | 옷 갈아입기·드레스업 |
| `T_SKIT` | 상황극·콩트 |
| `T_TALK` | 말하기 중심 |
| `V_VLOG` | 브이로그 |
| `COLLAB` | 협업·듀엣 |
| `OTHER` | 위에 안 맞는 것 |

접두어가 축이다. `B` 뷰티, `F` 패션, `T` 토크, `V` 브이로그. 새 축을 만들면 접두어부터 정한다.

**`OTHER` 비율이 20%를 넘으면 분류 체계를 다시 본다.** 코드가 현실을 못 담고 있다는 신호다.

## 3. 샘플링

채널당 **쇼츠 탭 최신 120편**이 기본 표본이다. 이유는 셋이다.

1. 최신순이라 알고리즘 노출 변화의 영향을 덜 받는다
2. 120편이면 포맷당 10편 안팎이 확보된다
3. 채널마다 같은 수를 뽑아야 채널 간 비교가 성립한다

### 수집 경로

`search.list`를 쓰지 않는다. 100유닛이다. 이렇게 한다.

1. `channels.list(part=contentDetails)`로 uploads 재생목록 ID를 얻는다 — 1유닛
2. `playlistItems.list`로 최신순 순회, 50개씩 3페이지 — 3유닛
3. 얻은 영상 ID를 50개씩 묶어 `videos.list(part=snippet,statistics,contentDetails)` — 3유닛

채널 하나에 **7유닛**이다. 후보 채널 5곳이면 35유닛. 하루 예산 10,000의 0.35%다.

쇼츠만 남기려면 `contentDetails.duration`으로 거른다. 3분 이하를 쇼츠로 본다. 다만 2026년 7월 이후 업로드 상한이 늘어 길이만으로 판정하면 오분류가 난다. 길이 기준을 결과물에 적는다.

### yt-dlp를 쓰지 않는 경우

공식 API 경로가 기본이다. yt-dlp는 약관 저촉이고 봇 확인 요구로 자주 막힌다. 위 3단계로 같은 데이터가 나온다.

다만 **자막이 필요하면 공식 경로가 없다.** `tools.md`의 비공식 경로를 리스크 고지 후 승인받는다.

## 4. 경과일 보정

게시한 지 오래된 영상은 조회수가 누적돼 있다. 그대로 비교하면 오래된 영상이 이긴다.

```
일평균 조회 = 조회수 / max(경과일, 1)
```

경과일은 수집일에서 게시일을 뺀 값이다. 게시 당일 영상은 1로 본다.

**이 보정은 근사다.** 실제 조회수는 초기에 몰리고 이후 평탄해진다. 일평균은 오래된 영상을 과소평가한다. 90일이 넘는 영상과 30일 이내 영상을 같은 표에 놓을 때는 그 사실을 각주로 단다.

## 5. 채널 내부 상대 지수

채널 크기를 지우는 단계다.

```
채널 중앙값 = 그 채널 영상들의 일평균 조회 중앙값
포맷 지수 = (그 포맷 영상들의 일평균 조회 중앙값) / (채널 중앙값)
```

**평균이 아니라 중앙값을 쓴다.** 쇼츠는 한 편이 터지면 분포가 무너진다. 평균은 그 한 편에 끌려간다.

지수 1.0은 그 채널 평범한 영상만큼이다. 1.5는 채널 평균의 1.5배다.

## 6. 채널 효과 판정

**포맷이 좋은 것과 그 채널이 그 포맷을 잘하는 것은 다르다.**

판정 규칙:

> 한 채널만 지수 1.5 이상이고 다른 두 채널이 1.0 미만이면, 포맷 효과가 아니라 채널 효과로 본다.

그래서 **포맷당 최소 2채널 표본이 필요하다.** 1채널뿐인 포맷은 지수를 내되 "채널 효과 판정 불가"를 명시한다. 결론에 쓰지 않는다.

표본이 1채널인 포맷은 커버리지 공백으로 기록하고, 그 포맷을 하는 다른 채널을 후보에 추가한다.

## 7. 조회수/구독자 배율

신규 채널처럼 구독자가 없거나 적을 때 쓴다.

```
배율 = 조회수 / 구독자수
```

배율이 높다는 것은 **구독자 밖으로 나갔다**는 뜻이다. 탐색 노출이 작동했다는 신호다.

구독자 0인 채널에는 정의되지 않는다. 그 경우 배율은 벤치마크로만 쓴다. 후보 채널의 배율을 보고 어떤 포맷이 구독자 밖으로 나가는지 판단한다.

**주의**: 구독자 수는 API에서 세 자리 유효숫자로 반올림된다. 소규모 채널의 배율은 오차가 크다. 구독자 1,000명 미만 채널의 배율은 자릿수만 본다.

## 8. 보고 형식

```
[포맷 지수] 채널 N곳 · 영상 M편 · 수집 {날짜}

| 포맷 | 표본 채널 | 영상수 | 지수 중앙값 | 채널별 지수 | 판정 |
|---|---|---|---|---|---|
| B_ASMR | 2 | 41 | 1.8 | 1.9 / 1.7 | 포맷 효과 |
| F_DRESSUP | 1 | 16 | 2.1 | 2.1 | 판정 불가 (1채널) |

[커버리지 공백] (표본 1채널 이하인 포맷과 보완할 후보 채널)
[경과일 분포] (90일 초과 영상 비율. 높으면 보정 근사의 한계를 명시)
[다음 행동] (하나만)
```

## 9. 하지 않는 것

- 채널 크기가 다른데 절대 조회수를 나란히 비교
- 중앙값 대신 평균으로 지수 산출
- 1채널 표본 포맷을 포맷 효과로 결론
- 경과일 보정 없이 게시일이 다른 영상 비교
- 구독자 1,000명 미만 채널의 배율을 소수점까지 제시
- `OTHER` 비율이 높은 채로 분류 결과를 결론에 사용
- 헤더 없는 TSV에 열을 중간 삽입
